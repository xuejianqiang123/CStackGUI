# T5 · 交付团（`t5-delivery/`）

> 本目录**不是技能**，只是分组的壳：团队说明一律只写 `README.md`。
> 若在这里放 `SKILL.md`，技能扫描会停止下钻、把整团吞成一个技能，成员全部消失。

**使命**：按规范分批提交，需要时开 PR
**何时点将**：审查通过后、提交、保存改动、创建 PR
**团长**：`git-commit-style`

## 成员（按上场顺序）

| # | 技能 | 一句话 |
|---|---|---|
| 1 | `git-commit-style` | 本项目唯一的提交规范与提交流程 |
| 2 | `piv-create-pr` | 基于已提交的改动创建 Pull Request / Merge Request，包含清晰的描述与关联信息 |
