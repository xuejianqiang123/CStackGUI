# 非破坏性文件操作（不删为先）

**输入**：$ARGUMENTS

删文件是**不可逆**动作，而且本 IDE 对删除类操作会弹权限确认：一次任务里零散删十几样东西，
就等于把用户晾在十几个弹窗前面（用户原话："很频繁、触发风控、要我手动允许，很不友好"）。
所以默认立场是：**能不删就不删；真要删，攒成一次、说清楚、只请求一次批准。**

## 核心原则

1. **删除不是编辑手段**：改内容用覆盖写，别"先删再建"；清空自己的输出文件也用写空内容，
   不走删除。
2. **临时产物落在 `build\`**（已被 `.gitignore` 忽略）：探针脚本、截图、日志、提交信息文件
   都写这里，**做完不用删**——留着无副作用，删了反而触发一次确认。
3. **删除必须是一次成批的、精确到完整路径的操作**，并在同一轮回复里先给"删除清单 +
   原因 + 为什么没有替代方案"，让用户一次批准搞定。

## 场景 → 替代做法（先查这张表）

| 你的目的 | ❌ 别这么干 | ✅ 改成 |
| --- | --- | --- |
| 改某段代码 | 删掉文件重新生成 | `replace_in_file` / `write_to_file` 覆盖 |
| 清空一个文件内容 | 删了再建 | `write_to_file` 写空内容（或 `> file` 截断） |
| 重新全量编译 | 删 `build\obj`、删 `build\lib` | **不要删**：脚本自比时间戳；重编 `gcc -o` 会直接覆盖 `.o`，`ar rcs` 覆盖归档 |
| 重建输出目录 | `rmdir /s /q <out>` + `mkdir` | 直接往里写；`mkdir` 遇到已存在目录只报错、不破坏 |
| 批量清理产物（`*.o` / `*.a` / 旧 exe） | `del /s /q`、通配符删除 | 不做。产物已被 gitignore / 已被覆盖；非要清就列为一次性清单让用户批准 |
| 临时探针 / 调试脚本 / 截图 | 建在工程里，用完 `delete_file` | 写到 `build\`（含 `_tmp` 命名），**留着不删** |
| 调试用 C 探针 | 新建 `.c` 进工程再删 | 优先脚本内联/复现命令；非落盘不可就放 `build\` |
| 被 git 跟踪的文件要"还原"（如重链过的 `examples\gallery\gallery.exe`） | 删除它 | `git restore <file>`（不改语义，不算删除） |
| 提交信息多行文本 | 建文件、提交后删 | 写 `build\_msgN.txt`（build\ 被 gitignore），留着 |
| 撤回自己刚做错的产物 | 删除 | `git restore` / 重新覆盖写正确的版本 |

## 硬红线（一律不做）

- ❌ `rmdir /s /q`、`rd /s /q`、`del /s /q`、`Remove-Item -Recurse`、`git clean -fd(x)`
- ❌ 带通配符的删除（`Remove-Item build\*`、`del runtime\src\*.o`、`rm -rf *`）
- ❌ 删 `.codebuddy\`（项目数据目录）、`runtime\`、`designer\src\`、`docs\`、
  `examples\` / `apps\` 里任何手写文件
- ❌ 删工作区之外的路径、删用户数据目录（`%LOCALAPPDATA%\<exe名>\`）
- ❌ 把"删除"当成编辑/重构手段（"先删掉再重建"）

## 确实需要删除时（流程）

1. **先找替代**：过一遍上面那张表，能覆盖/改名/保留就停在那里。
2. **攒成一次**：本次任务所有要删的东西合并成**一条命令 / 一次工具调用**，
   每条路径写完整绝对路径，不用通配符。
3. **先说明再执行**：回复里给出
   `删除清单：<路径> — 原因 — 为什么无法替代`，然后只请求这一次批准。
4. **用户明确点名要删**的（或用户自己要求清理）→ 也按第 2、3 步做，但不必再劝替代方案。
5. 例外：你**本次刚创建**、且位于 `build\` 里的单个临时文件，可以直接删；但仍建议保留
   （`build\` 不进版本库，留着零成本）或并入一次性清单。

## 输出

本技能是**约束类**，没有独立产出物（不写报告、不改仓库文件）。要求在回复里体现：

- 涉及删除时：一行「删除清单 + 原因 + 替代方案（若有）」，且**整个任务只请求一次批准**；
- 任务收尾时：临时文件一律留在 `build\`，**不要在结尾顺手清理**；
- 如果发现自己在同一轮里连续三次以上动删除类命令 → 停下来，合并成一次再提。

## 关联

- 提交/工作区整洁：`git-commit-style`（用 `git restore` 处理"重链导致 exe 显示已修改"这类问题）
- 构建与验证入口见根 `README.md` 与 `.codebuddy/memory/MEMORY.md`（`build\` 只放中间产物，可随时删但**没必要删**）
