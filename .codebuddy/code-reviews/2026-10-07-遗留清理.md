## 否掉的项（不许省）

- **`main.c` 自动重新生成**：仍然不做。用户手改过的 `main.c` 一覆盖就没了，而它是纯样板、价值低、风险高。
  本轮的处置是"**只提醒**"（不同步就说一句），既不冒数据丢失的险，也不让用户蒙在鼓里。
- **自动删除"已不再绑定"的回调**：不做。判"这个函数真没人用了"在 C 里没有可靠答案（`grep` 也不可靠，
  可能有函数指针），所以改成**报出来让用户自己决定**。
- **给 `failed` 单开一个 UI 字段**：不做。它当前调用路径不可能非空（主进程拿到的永远是生成器产物），
  为一个不可达状态加 UI 面就是给假想需求写代码。留在纯函数契约里 + `log()` 留线索，够了。
- 上一轮已否掉的四项（整份重写+区域标记 / main.c 重生成 / 删死回调 / 合并放渲染进程）**维持否决**。
