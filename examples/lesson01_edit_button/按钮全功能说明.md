# 入门 01 · 按钮全功能说明

本目录的 `lesson01_edit_button` 在「编辑框 + 按钮」最小骨架之上，额外演示了**按钮的全部能力**：

- **背景图**：在 `.cgui` 里用 `src` 字段给按钮指定一张图片，运行时拉伸铺满整个按钮（圆角裁切），文字画在图上。
- **全部事件**：按钮支持 13 种事件，全部绑到同一个 C 函数 `on_full_event`，靠 `cg_event_name()` 等 API 在回调里分流。

界面在 `lesson01_edit_button.cgui`，行为在 `main.c`。

---

## 1. 背景图（`src` 字段）

按钮的 `src` 与图片控件（`image`）、图标按钮（`iconbutton`）共用同一个字段，由运行时按需加载，换图会自动释放旧位图。

```jsonc
{
  "id": "btn_full",
  "type": "button",
  "rect": { "x": 300, "y": 100, "w": 104, "h": 40 },
  "text": "全功能",
  "style": { "fg": "#FFFFFF" },   // 图上文字用白色，深色图才看得清
  "src": "assets/icon.png"         // 相对 .cgui 所在目录
}
```

要点：

| 项 | 说明 |
|----|------|
| 支持的格式 | `png` / `jpg` / `bmp` / `gif`（gif 取第一帧，不播放） |
| 摆放方式 | **拉伸铺满**整个按钮，再裁进圆角里；不保持比例 |
| 路径 | 相对 `.cgui` 所在目录；找不到只警告，按钮照常画成纯色 |
| 文字颜色 | 默认按底色自动黑/白；设了 `style.fg` 就听你的（图上没法自动算对比度） |
| 没有 `src` | 就是一个普通主题色按钮，行为完全不变 |
| 与 `iconbutton` 区别 | `iconbutton` 把图**等比缩放到控件内**当图标；`button` 把图当**背景铺满** |

本例把 `examples/gallery/assets/icon.png` 拷到了 `assets/icon.png`，所以整个目录搬走也能跑。

> **挑图注意**：别用自带文字的图当按钮背景——运行时会把按钮的 `text` 画在图上，图里自带的字和它叠在一起，看起来就像「渲染乱了」。另外按钮的 `text` 留空时**运行时不会画任何文字**，如果你在空文字的图片按钮上看到了字，那一定是图片自己带的。

## 2. 按钮支持的 13 种事件

| 事件名 | 触发时机 | 回调里常用的取值 |
|--------|----------|------------------|
| `click` | 左键单击抬起 | — |
| `dblclick` | 左键双击 | — |
| `mousedown` | 左键按下 | `cg_event_x` / `cg_event_y`（相对窗口客户区） |
| `mouseup` | 左键松开 | 同上 |
| `rdown` | 右键按下 | 同上 |
| `rup` | 右键松开 | 同上 |
| `mousemove` | 鼠标在按钮上移动 | 同上；高频，建议只更新状态栏 |
| `gotfocus` | 按钮获得键盘焦点 | — |
| `lostfocus` | 按钮失去键盘焦点 | — |
| `keydown` | 键按下（焦点在按钮时） | `cg_event_key`（虚拟键码） |
| `keyup` | 键松开 | 同上 |
| `char` | 可打印字符键入 | `cg_event_key`（字符码，如 `'A'`） |
| `wheel` | 滚轮滚动 | `cg_event_delta`（正数=向上） |

取值 API（都在 `cstackgui.h` 里，参数传 `self` 即触发事件的控件）：

```c
int x   = cg_event_x(self);     // 鼠标 x（相对窗口客户区）
int y   = cg_event_y(self);     // 鼠标 y
int vk  = cg_event_key(self);   // keydown/keyup=虚拟键码，char=字符码
int d   = cg_event_delta(self); // 滚轮滚动量（正=上）
int mod = cg_event_keys(self);  // 修饰键：1=Ctrl 2=Shift 4=Alt
const char *name = cg_event_name(ev); // 事件名字符串，如 "click"
```

## 3. 一个函数绑多种事件

13 种事件在 `.cgui` 里都填同一个名字 `on_full_event`：

```jsonc
"events": {
  "click": "on_full_event", "dblclick": "on_full_event", "mousedown": "on_full_event",
  "mouseup": "on_full_event", "rdown": "on_full_event", "rup": "on_full_event",
  "mousemove": "on_full_event", "gotfocus": "on_full_event", "lostfocus": "on_full_event",
  "keydown": "on_full_event", "keyup": "on_full_event", "char": "on_full_event",
  "wheel": "on_full_event"
}
```

C 侧用 `cg_event_name(ev)` 分流；高频的 `mousemove` / `gotfocus` / `lostfocus` 只更新状态栏，其余打到结果标签方便对照：

```c
static void on_full_event(cg_widget_t *self, cg_event_t ev, void *user)
{
    cg_app_t *app = cg_app_of(self);
    int x = cg_event_x(self), y = cg_event_y(self);
    int k = cg_event_key(self), d = cg_event_delta(self);
    (void)user;

    switch (ev) {
    case CG_EVENT_MOUSEMOVE:  /* 只动状态栏，不打扰结果区 */
    case CG_EVENT_GOTFOCUS:
    case CG_EVENT_LOSTFOCUS:
        /* ... set_status ... */ return;
    default: break;
    }

    char buf[160];
    switch (ev) {
    case CG_EVENT_CLICK:    snprintf(buf, sizeof(buf), "事件：click（左键单击）"); break;
    case CG_EVENT_KEYDOWN:  snprintf(buf, sizeof(buf), "事件：keydown（虚拟键码 %d）", k); break;
    case CG_EVENT_CHAR:     snprintf(buf, sizeof(buf), "事件：char（字符 '%c'，码 %d）", k, k); break;
    /* ... 其余事件类似 ... */
    }
    cg_widget_set_text(cg_find(app, "lab_result"), buf); // 内部会自己拷贝字符串
}
```

> 提示：`cg_widget_set_text` 内部拷贝了字符串，所以直接传栈上的 `buf` 即可，不用 `cg_str_dup`。

## 4. 怎么跑

```bat
build-app.bat examples\lesson01_edit_button
```

不开窗自检（解析 + 把每个事件都真调一遍回调）：

```bat
examples\lesson01_edit_button\lesson01_edit_button.exe --selftest
```

双击 `lesson01_edit_button.exe` 也能跑（自动在 exe 旁边找 `.cgui`）。

把鼠标移到右侧「全功能」按钮上、点它、右键点它、让它获得焦点后敲键盘、滚轮滚它——结果区和状态栏会实时显示对应的事件名与参数。
