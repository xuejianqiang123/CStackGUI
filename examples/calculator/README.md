# 计算器：一个 .cgui 界面 + 一份纯 C 状态机

`calculator` 是 CStackGUI 里最小的完整示例：75 行界面描述（`calculator.cgui`）+ 约 580 行 C（`main.c`）。
鼠标点键和键盘输入走同一套按键函数，带错误态、退格、正负号和百分比。

## 怎么跑

```bat
rem 仓库根目录
build-app.bat calculator
examples\calculator\calculator.exe
examples\calculator\calculator.exe --selftest   rem 无窗自检
```

也可以直接用画布打开 `calculator.cgui` 按 F5。工程里没有别的依赖，删掉 `lib/` 重新编译也行。

## 操作

鼠标点 20 个键都有效，键盘是同一套动作：

| 键 | 作用 |
| --- | --- |
| `0`-`9`、小键盘数字 | 输入数字 |
| `.`、小键盘 `.` | 小数点（重复按只认第一个） |
| `+` `-` `*` `/` | 四则运算（主键盘 `Shift`+`=` 是加号，单按 `=` 是等于） |
| `Enter`、小键盘 `Enter` | 等于 |
| `%` | 当前数 ÷ 100 |
| `Esc` | 全部清除（AC） |
| `Backspace`、`Delete` | 退格 |
| `±` | 只在按钮上，键盘没绑——小键盘的 `-` 已经给了减法，不抢 |

## 界面

`.cgui` 里只有 2 个 label（表达式回显 / 主显示）和 20 个 button，样式 5 个：

| 样式 | 用途 | 关键字段 |
| --- | --- | --- |
| `expr` | 顶部表达式回显 | Consolas 11、右对齐、`#49454F` |
| `value` | 主显示 | Consolas 34、右对齐、`#1D1B20` |
| `key` | 数字键 | 白底 `#FFFFFF`、圆角 16 |
| `key_op` | 运算键 | 不写 `bg`，用运行时浅色主题的默认按钮底色 |
| `key_eq` | 等号 | 紫底 `#6750A4` |

**实心按钮的文字色由运行时按底色亮度自动取黑/白**（`cg_skin.c` 的 filled 分支），样式里写 `fg` 不生效——所以上面几个样式只给底色，不再逐键配色。想换配色改 `bg` 就够，文字会自己跟着翻。

窗口底色写在 `info.bg`（`#F3EDF7`）。这个值走的是 `cgw_theme_window_bg()`，返回 `0xRRGGBB`；Win32 的 `COLORREF` 是反的，运行时在用之前会调 `cgw_to_colorref()` 转一次。少这一层，`#F3EDF7` 会画成 `#F7EDF3`——肉眼只是"紫一点"，很难发现，所以两边都留了注释。

## 逻辑

状态全在 `g_calc` 里：`acc`（左操作数）、`cur`（当前值）、`entry[]`（正在输入的串）、`entering` / `have_dot`、`pend`（待执行的运算符）、`last_op` / `last_rhs`（供连按等号复用）、`error`、`expr[]`（顶部回显）。

几条刻意的取舍：

- **输入期只攒字符串，按等号才转 double**：`0.1 + 0.2` 显示 `0.3`，不是 `0.30000000000000004`。显示统一走 `%.12g`。
- **先按先算，没有优先级**：`1 + 2 * 3` 得 9。这是"简单计算器"的语义，和 Windows 计算器的标准模式一致；要支持括号和优先级就是另一个东西了。
- **连按 `=` 重复上一次运算**：`2 + 3 ==` → 8，`==` 之后仍是 8。
- **除以零不崩也不卡**：显示"不能除以零"，按任意数字或退格直接回到可用状态。
- **退格删空停在 `0`**，不跳回上一个结果——跳回去会让人以为自己删错了。
- **百分比只做 ÷100**，不做"200 + 10%"的隐式计算：算 `200 + 10%` 请自己写 `200 + 20`，行为写死比猜意图可靠。
- **最多 13 位数字**（`ENTRY_DIGITS`）：324px 的显示区再长就撑破了，第 14 位直接吃掉。
- **一个回调管 20 个键**：`on_pad_click` 按 id 前缀/名字分发，`btn_0`..`btn_9` 按前缀认，其余按名字认；不用给 20 个按钮各写一个回调。
- **键盘只绑窗口一次**：点击按钮不会把焦点抢走（按钮分支不 `SetFocus`），所以 `keydown` 绑在窗口上就够。

## 验证

```bat
examples\calculator\calculator.exe --selftest
```

输出 `控件 22 个, 触发回调 20 次, 未登记 0 个, 事件不支持 0 个, 绑定出错 0 个, 动作出错 0 个, 样式引用失效 0 个`，最后一行 `selftest OK`——它会把每个按钮点一遍，按钮 id 和回调对不上会直接报出来。

业务逻辑另有一套 31 条用例（四则、连按等号、除零、退格、小数点、位数上限、百分比、键盘路径），用一个临时探针工程把 `main.c` 整个 include 进来直接调静态函数跑，跑完删掉、没入库。要回归时按同样办法建一个即可。

## 文件

| 文件 | 说明 |
| --- | --- |
| `calculator.cgui` | 界面定义（画布里可直接编辑） |
| `main.c` | 全部行为：状态机、按键函数、键码映射、回调、自检与画初值 |
| `calculator.exe` / `lib/` | 构建产物（不入库） |
