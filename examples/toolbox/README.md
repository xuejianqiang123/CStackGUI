## 一、这是什么

`toolbox`（工具箱启动器）是 CStackGUI 框架的示例工程之一。CStackGUI 是一个自研的 Win32 GUI 框架，核心思路是：

- **界面在 `.cgui` 文件里**（JSON 描述，用配套画布设计器可视化编辑，F5 直接编译运行）；
- **行为在纯 C 代码里**（回调函数按控件 id 绑定，界面与逻辑彻底分离）；
- 配套 runtime（自绘控件、皮肤、注册表/文件/进程工具库）、designer（Electron 画布）、以及一组覆盖各控件的示例。

`toolbox` 的定位是"对标一个真实产品功能面"的综合示例——界面形态与行为逻辑都按真实工具箱的标准来做。

代码按功能职责拆成模块（`main.c` 只是入口：拼绑定表 + 界面就绪分发）：

| 文件 | 说明 |
| --- | --- |
| `main.c` | 入口：拼各模块绑定表、就绪时依次初始化各模块 |
| `modules\tb_tools.c` | 工具命令表（`k_tools[]`）、按钮墙启动、最近使用、页计数 |
| `modules\tb_search.c` | 全局搜索（名称/命令双字段过滤） |
| `modules\tb_mytools.c` | 我的工具（mytools.ini 槽位） |
| `modules\tb_opts.c` | 成对开关（沙箱注册表键，真改真还原） |
| `modules\tb_rmenu.c` | 右键菜单管理（六位置扫描、批量禁用/备份删除/还原） |
| `modules\tb_ui.c` | 底栏功能带（切页/日志窗/深浅主题/关于） |
| `modules\tb_log.c` | 日志列表与状态栏回执（各模块共用） |
| `toolbox.cgui` | 界面定义（画布里打开可直接编辑） |
| `toolbox.exe` / `lib/` | 构建产物 |

## 二、功能介绍

### 1. 八页签工具启动器 + 全局搜索

常用 / 常用设置 / 我的工具 / 系统工具 / 清理优化 / 隐私设置 / 应用管理 / 右键增强，共 8 个页签，60+ 个内置工具（任务管理器、磁盘管理、计划任务……全是真实命令启动）。

底栏有完整的功能带：**「本页 X 个（共 Y 个）」实时计数** + 搜索 / 日志 / 设置 / 关于 / 检查更新。全局搜索按名称和命令双字段过滤，还有一个可选开关——输入关键字自动切到搜索页；「常用」页则自动记录你最近使用的工具。

> 【截图位 3：搜索命中列表 + 底栏计数】

### 2. 我的工具：改一个 ini 就能加工具，不用重编译

8 个槽位，配置文件在 `%LOCALAPPDATA%\toolbox\mytools.ini`：

```ini
[t1]
name=DeepSee
cmd=deepsee.exe --work D:\
[t2]
name=公司 OA
cmd=https://oa.example.com
```

保存后点「我的工具」页的**重新载入**，槽位按钮立刻生效；空槽位自动置灰。**加一个自定义工具连一行 C 代码都不用碰。**

### 3. 右键菜单管理：扫描、批量禁用、备份删除、一键还原

这是我认为最有意思的一页：

- **扫描**：枚举 HKCU + HKLM 下六个位置（文件 / 文件夹 / 文件夹空白处 / 桌面 / 磁盘 / 通用对象）的 `shell` 程序菜单与 `shellex` DLL 扩展项，逐项读取 `MUIVerb` / `command` / `LegacyDisable`，按来源分组（工具箱装的 / 程序装的 / 扩展项）、按状态分类（在用 / 已禁用 / 无命令）；
- **搜索 + 五路过滤**：标题子串搜索（忽略大小写），全部 / 未禁用 / 程序装的 / 已禁用 / 扩展项；
- **多选行真操作**（每次操作后自动重扫）：
  - **禁用** —— 写入 `LegacyDisable` 值；
  - **恢复** —— 删除该值；
  - **备份并删除** —— 先 `reg export` 导出 `.reg` 再整键删除，**动手前弹确认框列出全部路径**；
  - **还原本次改动** —— 禁用过的删值、删过的导入备份，「曾改动」列表可查。

> 【截图位 4：确认框列出待删路径】
> 【截图位 5：禁用后右侧状态翻转、"曾改动"列表】

工具箱自己装的两条右键菜单（复制文件路径 / 在此处打开终端）也是真装真撤，用 `reg.exe` 完成，删得干净。

### 4. 成对开关：模式照抄原版，落点绝不越界

「装上 / 撤掉」成对开关控制工具箱自身行为：日志镜像、日志时间戳、自动切搜索页、记录最近使用、右键沙箱标记。与很多工具不同的是，**这些开关的落点是程序自己的沙箱键** `HKCU\Software\CStackGUI\examples\toolbox` —— 真改真还原，配「查看曾改动 / 还原全部」，绝不碰系统键。

### 5. 日志与主题

日志是非模态对话框（可以边操作边看），支持镜像到控制台和行首时间戳（各由开关控制）；设置页是深浅主题一键切换，状态栏每次操作都有回执文案。

## 三、几个值得说的设计

**边界照实说，不在示例里装。** 界面上直接写明：系统区（HKLM）只读得到、修改需要管理员身份，未提权时点击会明确拒绝；shellex 扩展项只显示不给动。原版有彩色图标、106+ 工具，这里如实收在 60+——列表行带分类图标（iconlist 控件，2026-10-13 换装：最近使用页工具图标、右键页按分组三色），按钮墙仍用配色代替贴图；图标是 assets 下的分类图、不是从 exe 提取的——诚实差异在源码注释里逐条列着。

**自检红线。** 程序支持 `--selftest` 无窗自检：不启动任何程序、不读写磁盘、凡有副作用的操作先判断有没有窗口。按钮 id 与命令表不同步会在日志里报"不同步"，自检输出可直接 grep，适合放进 CI。

**数据落点全部可预期**：我的工具配置、`.reg` 备份、`app.log`（256KB 轮转）都在 `%LOCALAPPDATA%\toolbox\`，被写的注册表位置只有上面那个沙箱键。

**加一个内置工具只要两步**：`.cgui` 加按钮 + `modules\tb_tools.c` 的 `k_tools[]` 命令表加一行，计数和搜索自动生效。

## 四、怎么跑起来

```bat
rem 仓库根目录
build-app.bat toolbox
examples\toolbox\toolbox.exe
examples\toolbox\toolbox.exe --selftest   rem 无窗自检
```

也可以直接用画布打开 `toolbox.cgui` 按 F5。工程里还带了真机验证脚本（自动建探针键 → 模拟点击扫描/搜索/过滤/批量操作 → 注册表真值断言 → 截图取证 → 清理），改右键管理相关代码后可以一键回归。
