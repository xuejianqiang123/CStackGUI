# 环境与配置快照：INI 清单驱动的懒加载树，可增删改查

> 目录 `examples\envsnap\`　编译 `build-app.bat envsnap`　运行 `examples\envsnap\envsnap.exe`　自检 `envsnap.exe --selftest examples\envsnap\envsnap.cgui` → 控件 26 个 / 回调 13 次 /（未登记·事件不支持·绑定出错·动作出错·样式引用失效 全 0）→ `selftest OK`

## 一、它演示什么
两件事叠在一个示例里：
1. **懒加载的树**：左侧只先建两个根（环境变量 / 用户数据目录），**点开哪个才枚举哪个** —— 用户数据目录可能几百上千个文件，一次全展开会把消息循环堵住、界面假死，这和资源管理器「展开才读」是同一个道理。
2. **INI 清单驱动的节点 + 增删改查**：采集哪些环境变量、各挂哪个分组，不再写死在代码里，而是放在 exe 旁的 `envsnap.ini`（UTF-8）：`[分组]` 是节，`变量名=备注` 是键值（备注可空）。启动自动载入，没有就按内置清单生成一份；之后工具栏第二排就是清单的增删改查，**每次改动立即存回当前 ini** —— 文件是清单的唯一事实源，记事本手工改完点「导入INI」一样生效。
为什么不做「注册表浏览器」：运行时只提供按名读一个环境变量、注册表只有 HKCU 的字符串值读写，**没有枚举接口** —— 所以换成同方向的「环境与目录快照」，这条边界写在 `main.c` 文件头。

## 二、怎么用
1. 打开即可看到两个根（环境变量 / 用户数据目录）。点开某个分组才去采集它下面的条目。
2. 点树节点：右侧表格显示该节点的条目（变量值 + INI 里的备注 / 扩展名分类 / 目录条目）；点展开才枚举下一层。
3. 清单管理（第二排）：
   - **导入INI**：选任意一份 ini 重新载入清单，此后的增删改都存回它；取消则不动。
   - **添加**：打开一张**表单**（分组 / 变量名 / 备注 三个字段一次填完、点一次确定提交）；分组预填当前选中的组。
   - **删除**：删选中的变量；选中分组则整组连带删除（无二次确认，见下面的坑）。
   - **修改**：同一张表单预填现值，可改名 / 挪分组 / 改备注；挪组后原组空了会保留空节。
   - **查询**：按关键字过滤清单（分组 / 变量名 / 备注，ASCII 大小写不敏感），结果摆进右侧表格；点一下树节点就回到该节点的条目表。
   - 表单里校验不过（变量名为空 / 同组重名 / 分组满了）**只把红字提示写在框里，不关框** —— 改完直接再点确定，不用重走一遍流程。
4. 点「重新采集」清空树与节点表、重扫用户数据目录 —— **清单不动**（重采集 ≠ 重导清单）。
5. 点「导出快照」把当前**已采集**的内容写成 UTF-8 文本（清单段落带备注）；点「复制快照」把同一份送进剪贴板。
6. 命令行：`envsnap.exe`（自动找同名 `.cgui`）、`envsnap.exe xxx.cgui`、`--selftest`。

## 四、关键接口
`cg_file_read` / `cg_file_write` 整份读 INI / 落盘、`cg_open_file_dialog` 选要导入的 ini；`cg_dialog_open` / `cg_dialog_close` 开那张表单（`.cgui` 里的 `dlg_edit`，模态、返回值 1 = 确定）；`cg_widget_set_text` / `cg_widget_text` 预填与读回三个字段（对话框是同一个，每次打开都得整体重写）；`cg_widget_focus` 在 `show` 回调里把光标放到该填的那一格（原生是 open 时才懒建的，open 前 focus 是空操作）；`cg_input_box` 查询关键字（无窗口时返回 0 —— 自检天然走"没改"分支）；清单模型是两个静态表（变量行 + 分组名表），`load_children` 按它建树；`cg_tree_add` / `cg_tree_selected` / `cg_tree_clear` / `cg_tree_count`；`cg_env` 按名取一个环境变量；`cg_dir_list` 逐条枚举目录；`cg_save_file_dialog` 导出；`cg_clip_set_text` 复制快照。

## 五、容易踩的坑
- 懒加载的意义在于：不点开就不采集，避免一次全展开把消息循环堵住、界面假死。
- **添加 / 修改共用同一张表单**：值不会自己清 —— 每次打开前必须把三个字段整体重写一遍（`dlg_fill`），否则会留着上一次的输入；标题也用它区分（`cg_widget_set_text` 对窗口型控件就是改窗口标题）。
- **删除没有二次确认**（`cg_message_box` 只有确定钮，做不了"是否确认"）。删错了：清单文件就是唯一事实源，记事本改回来点「导入INI」即可（这也正是把清单放进 ini 的原因之一）。
- INI 必须 **UTF-8**（与导出快照同口径）；解析容错：BOM / `\r\n` / `;` `#` 注释 / 裸键都吃得下，重复键取先出现的并提示。
- 组名里的 `[ ]`、变量名里的 `=` 会在添加 / 修改时被剥掉，防止把 INI 格式写坏；变量满 256、分组满 32 有提示。
- 树展开 / 选中事件在自检里会被合成触发，里面不许读盘、不许弹框；清单在自检里用内置种子，五个管理按钮开头用 `cg_app_has_window` 拦截 —— **自检零磁盘副作用**。
- 运行时只提供「按名取一个环境变量」，**没有枚举环境变量的接口**，所以才需要这份清单。
