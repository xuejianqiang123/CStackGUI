# apps\ —— 你自己的界面工程放这里

画布（`CStackGUI.exe`）点「导出 C 骨架」时，默认就导到这个目录下的 `apps\<名字>\`。

```
apps\<名字>\
  名字.cgui            画布存出来的界面
  名字_ui_events.c     ← 你要写业务逻辑的文件（画布只往里补缺的回调桩，不动你写的任何一行）
  名字_ui_events.h     生成物（每次导出都会重写）
  main.c               生成物（只在首次导出时写；之后不覆盖，怕抹掉你自己加的）
  名字.rc              生成物：程序图标 + 版本信息（来自画布「程序配置」）
  build.bat            生成物：双击即可编译本工程
  lib\libcstackgui.a   编译时自动放的运行时库副本
  名字.exe             编译产物，双击即跑
```

在项目根目录编译：

```bat
build-app.bat <名字>
```

**注意**：仓库自带的示例不在这个目录，它在 `examples\` 下
（`examples\gallery` 是控件陈列室·三合一）。
这个目录是留给你的，别把它当成示例目录。
