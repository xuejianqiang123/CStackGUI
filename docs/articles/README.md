# CSDN 系列文章（工作稿）

这个目录放的是**对外发布的教程文章**工作稿，一篇对应一课（另有导读与实战篇可选）。
文章里的控件字段、事件名、状态栏文案、自检数字**全部来自仓库里的真实示例**，不是凭印象写的：
发布前如果代码改过，请按下面的"事实来源"重新核一遍。

## 每篇的固定结构（保持六篇一致，读者才不用重新适应）

1. **开篇 hook**：这篇解决什么问题 / 会看到什么（3~5 行，别写"随着互联网的发展"）；
2. **跑起来**：编译命令 + 自检命令 + 该课的自检数字；
3. **一屏总览**：控件清单表（`类型名 | 一句话 | 有事件吗`）；
4. **逐个讲**：`.cgui` 片段 → C 回调片段 → 一句"为什么这么写"；
5. **踩坑清单**：这一课真实踩过的（都在 `main.c` 注释与 `hint` 里）；
6. **验收**：`--selftest` 期望输出；
7. **下一篇预告 + 系列导航**。

## 配图

- 整窗图用 `tools\shot.ps1`；**要呈现"点了之后的样子"**（聚焦环、选中态、状态栏那句话）用
  `tools\shot-widget.ps1 -ClickX/-ClickY`，它会先真点一下再按客户区坐标裁块放大。
- 触发点击时注意两条：**会切换的控件别连点两下**（点两下等于没点）；
  **点击有没有生效要看"该变的东西变没变"**，只看图不算证据。（这两条是 2026-09-23 实测踩出来的。）
- 图都产出到 `build\`（已被 `.gitignore` 忽略，不进仓库）；每篇文章末尾有"配图清单"表，
  写明文中每个 `![图 N]` 该上传 `build\` 下哪个文件。
- CSDN 编辑器里直接粘贴图片即可；**发布前把 `图1-整窗.png` 这类占位换成 CSDN 的图片地址**。

## 图片放哪

- `docs\articles\images\<篇号>\` 里放着**各篇正文直接引用的图**（名字与文中的 `![图 N](...)` 一致）——
  用编辑器打开文章就能直接看到图，不用先去 `build\` 找。
- `build\` 里是原始截图（含整窗版与未采用的备选）。**改图流程**：在 `build\` 重截 → 拷进
  `images\<篇号>\` 覆盖同名文件 → 文章自动跟着变。
- 两处内容必须一致：正文的链接只有 `images\` 下这份，`build\` 那份只是来源。

## 发布建议

- **标签/分类**：C语言、Windows、GUI、桌面应用、CStackGUI（新框架名建议固定，便于系列互链与检索）。
- **系列互链**：每篇末尾的"系列导航"把上一篇/下一篇的 CSDN 链接补上；第一篇发布后再回填。
- **标题**：`【CStackGUI 入门 0N】主题：一句具体的话`（例：`把界面"画"出来：12 类基础控件与容器的相对坐标`）。
- **摘要/首段**：写"读完这篇你能得到什么"，不要写框架自夸。

## 注意

- 文章里**不要**出现内部路径、内部工具名（`check-format` 这类门禁命令可以留，读者也需要）；
  用户在意的只有"我怎么跑起来、我怎么写回调"。
- 示例代码一律照 `main.c` 抄，**不要为了文章好看而简化到不能编译**：
  真抄一遍、真编译一遍，读者才不会卡在第一步。
